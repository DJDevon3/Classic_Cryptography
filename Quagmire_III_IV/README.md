# Quagmire III & IV Encryption & Decryption
A single python script that can encrypt or decrypt both Quagmire III or IV

### Customizable:
- Keyworded Alphabets
- Displays Entire Vigenere Table
- Displays entire repeated keyword, plaintext, and ciphertext
- Ciphertext Mode Switch
- Plaintext Mode Switch
- Saves Results to File
- Filename formatted with Encrypt/Decrypt, Quagmire Mode, Keywords, and first 10 characters of ciphertext


### Usage:
To run the script simply use command prompt and point python to where the script is located. Here is an example of a command:
- C:\Users\Devon\Documents\Kryptos Scripts>python Quagmire_III_IV.py
- It will then run the program, print out the matrix to the prompt, and save a text file with the results.
