# Quagmire III Brute Force with Crib
Python script that uses crib words at specific index positions to brute force all A-Z possibilities of a given key length

### Customizable:
- Keyworded vigenere style alphabets
- Required: at least 1 crib word
- Required: only 1 integer value for key length at a time (does not cycle from 1 to n lengths)
- Displays how many matches, the keyword used, and associated plaintext decryption using the keyword
- Calculates keyspace and displays amount of keys searched
- Calculates processing time taken (after file saved)
- Saves Results to File
- Filename formatted with Mode, Keyword Length, Keyword Index Position & Keyword, and first 10 characters of ciphertext


### Usage:
To run the script simply use command prompt and point python to where the script is located. Here is an example of a command:
- C:\Users\Devon\Documents\Kryptos Scripts>python Brute_Force_with_Crib.py
- It will then run the program, print out the matrix to the prompt, and save a text file with the results.
