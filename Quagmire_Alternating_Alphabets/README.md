# Quagmire Alternating Alphabets
A novel method using multiple alphabets in alternating opposite directions

### Customizable:
- Keyworded Alphabets
- Alphabet Direction
- Ciphertext Mode Switch
- Saves to File

Geared towards the Kryptos Sculpture challenge created by Jim Sanborn located at CIA Headquarters in Langley, VA.
