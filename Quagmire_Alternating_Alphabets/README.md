# Quagmire Alternating Alphabets
A novel method using multiple alphabets in alternating opposite directions

### Customizable:
- Keyworded Alphabets
- Alphabet Direction
- Ciphertext Mode Switch
- Saves to File

Geared towards the Kryptos Sculpture challenge created by Jim Sanborn located at CIA Headquarters in Langley, VA. 

### Usage:
To run the script simply use command prompt and point python to where the script is located. Here is an example of a command:
- C:\Users\Devon\Documents\Kryptos Scripts>python Quagmire_Alternating_Alphabets.py
- It will then run the program, print out the matrix to the prompt, and save a text file with the results.
